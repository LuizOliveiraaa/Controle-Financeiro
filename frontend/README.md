# Frontend scaffold for Controle-Financeiro

This scaffold includes:
- Vite + React + TypeScript
- Tailwind CSS
- React Router
- Axios integration with refresh token interceptor
- Basic pages: Login, Register, Forgot Password, Reset Password, Dashboard (protected)

To run:

cd frontend
npm install
npm run dev

The app expects the backend at the same origin under /api/v1. In development you can run the backend at http://localhost:5000 and use a proxy if needed.
